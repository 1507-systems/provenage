presents itself as the official record or as a view onto the government's.

## How this index is used

- Before building a new capability, check whether a project here already does it
  and whether it can be adopted or interoperated with.
- Anything adopted is attributed in [NOTICE](../NOTICE) with its license. Nothing
  has been adopted yet.
- To add or correct an entry, open a pull request with a link to the public page
  you relied on.
