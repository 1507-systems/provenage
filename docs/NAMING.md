# Naming

## Why Provenage

Provenage combines "provenance", the record of where something came from and how it
got here, with "-age", as in lineage. It describes the project's central promise:
every civic record keeps its lineage.

Pronounced PROV-en-ij.

## Clearance

Chosen 2026-10-28 after a namespace and prior-art check. All of the following were
clear on that date:

- GitHub (users, organizations, repositories)
- npm
- PyPI
- crates.io
- Domain registration status for .org, .dev and .io
- Web search for civic, govtech and journalism use of the name

Trademark registration status has not been checked.

## Former working title

"Civic Data Core". It was dropped because it collided with Townlight's CivicCore
and was too generic to search for.
